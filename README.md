# Digital-election-system-Ver.0
学校選挙 電子投票システム

学校の委員会選挙（約300人・iPad約10台）を、紙の投票用紙のかわりに電子投票で行うためのシステムです。 投票画面はiPadのSafariで動き、投票データはまずiPadの中に保存してから、Googleスプレッドシートへ送ります。通信が切れても、確定した票は失われません。

すべて無料のサービス（GitHub Pages、Google Apps Script、Googleスプレッドシート）だけで動きます。

特徴
迷わず投票できる： 候補者を大きなボタンで選び、確認を2回はさんで投票します。画面はスクロール不要です。
票を失わない： 「投票する」を押すと、まずiPad内（IndexedDB）に保存し、保存できてから完了画面を出します。送信に失敗した票は「未送信」として残り、あとで自動または手動で送り直せます。
二重登録を防ぐ： 票ごとに固有のIDをつけ、GAS側で同じIDを二重に登録しません。
匿名： 氏名や学籍番号は保存しません。
秘密をコードに置かない： 候補者名・管理者パスワード・受付のON/OFF・使える端末は、すべてスプレッドシート側で管理します。このリポジトリは公開されても問題ありません。
見た目： デジタル庁デザインシステムの色・角丸・フォーカスリングなどを参考にしたスタイルです（公式のコンポーネントそのものではなく、独自に実装しています）。
構成
iPad（index.html）  ──保存──▶  IndexedDB（iPad内）
        │
        └─送信─▶  Google Apps Script（Code.gs）  ──▶  Googleスプレッドシート
ファイル	役割
index.html	投票画面・管理画面（HTML/CSS/JavaScript、1ファイル）
Code.gs	スプレッドシートに貼るGoogle Apps Script（設定の配信・票の受信・集計）
セットアップ
1. スプレッドシートとGAS
新しいGoogleスプレッドシートを作り、「拡張機能」→「Apps Script」を開きます。
Code.gs の中身を貼り付けて保存します。
関数 setup を一度だけ実行します（権限の許可が求められます）。次のシートができます。
シート	内容
設定	選挙名、選挙ID、受付（ON/OFF）、管理者パスワード
候補者	区分（1男子委員長・2女子委員長・3男子副委員長・4女子副委員長）と名前
端末	使ってよいiPadの端末ID（A列）
votes	受信した票（自動で作られます）
「設定」シートの管理者パスワードを書き換え、「候補者」シートに名前を入れます。
「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」で、実行ユーザー：自分／アクセスできるユーザー：全員 にしてデプロイします。
発行されたURL（/exec で終わるもの）をコピーします。

コードを直したあとは、「デプロイを管理」から新バージョンに更新してください（「新しいデプロイ」を作るとURLが変わります）。

2. index.html にURLを入れる

index.html の次の行を探し、gas:'' の中にURLを貼ります。

js
const C={gas:'https://script.google.com/macros/s/……/exec',name:'',eid:'',open:true,R:[]};
3. GitHub Pagesで公開する

リポジトリの「Settings」→「Pages」で、公開するブランチとフォルダを選びます。公開されたURLを、各iPadのSafariで開きます。

4. iPadを登録する

最初は「この端末は未登録です」と端末IDが出ます。そのIDを「端末」シートのA列に貼り、画面の「もう一度確認」を押すと、投票画面が出ます。

使い方
投票者

「投票を開始」→ 4つの区分で候補者を選ぶ（そのたびに「はい」）→ 最終確認で「投票する」→ 完了画面。約6秒で次の人の画面に戻ります。途中でやめるときは右上の「投票せずに終了」を押します。

管理者

開始画面の右下「管理者」からログインします（ログインにはWi-Fiが必要です）。

この端末の投票数・未送信数の確認
「データを回収する」：未送信の票をスプレッドシートへ送る
「全端末の集計を見る」：スプレッドシートに届いた票の合計
「JSONバックアップ」：この端末の票をファイルに保存
受付のON/OFF

「設定」シートの「受付」を ON にしている間だけ、GASが票を受け付けます。OFF のときに投票すると、票はiPad内に残り、ON にしてから回収すると届きます。受付をOFFにするのは、全台の回収が終わってからにしてください。

注意事項
管理者パスワードや候補者名は、スプレッドシートに書きます。スプレッドシートの共有範囲は、管理者だけにしてください。
本人確認や二重投票の技術的な防止は行っていません。投票後は、来場者数（名簿の人数）と合計票数を突き合わせてください。
iPadのSafariで「プライベートブラウズ」を使ったり、「履歴とWebサイトデータを消去」を押したりすると、票のデータと端末IDが消えます。
投票ページを開いたあとで再読み込みや閉じる操作をしなくても済むように、受付中は開いたままにしてください。
投票データ（JSONバックアップなど）や、本番の候補者名・パスワードを、このリポジトリに入れないでください。
GitHubアカウントの二段階認証をオンにしてください。
